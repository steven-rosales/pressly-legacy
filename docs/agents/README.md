# Agent Artifacts

This directory preserves screenshots and other artifacts produced during
agent-assisted work.

These files are historical evidence, not current requirements, design tokens,
or acceptance results. A numbered folder may lack the context needed to explain
when, how, or why its images were captured.

For current Processor design rules, use
[apps/processor/DESIGN.md](../../apps/processor/DESIGN.md). For current delivery
status and verified evidence, use the relevant active Stateworks work item.

Do not delete unreviewed artifacts merely because their context is incomplete.
New durable evidence should include a date, viewport or runtime, scenario, and
the work item or decision it supports.
